# 🎙️ Windows向けリアルタイムボイスチェンジャー 要件定義書（.NET / WPF版）

## 1. 概要

本アプリケーションは、VTuber用途の**リアルタイム音声変換アプリ**である。  
マイクからの音声をリアルタイムで処理し、ピッチシフト・フォルマント変換・リバーブ・EQなどのDSPエフェクトを適用後、  
仮想オーディオデバイスへ出力する。  
OBSやDiscordなどから仮想マイクとして利用できることを目指す。

---

## 2. システム構成

```
[マイク入力]
   ↓  (WASAPI via NAudio)
[音声処理エンジン (.NET)]
   ├─ ピッチシフト
   ├─ フォルマント補正
   ├─ EQ（3バンド）
   ├─ エコー / リバーブ
   ├─ ノイズリダクション
   ↓
[出力: 仮想オーディオデバイス (VB-Cableなど)]
   ↓
[配信・通話アプリ（OBS / Discordなど）]
```

---

## 3. 機能要件

### 3.1 入出力制御
- マイク入力をリアルタイムで取得（WASAPI独占モード）
- スピーカー出力または仮想オーディオデバイスへ送出
- GUI上でデバイス選択可能

### 3.2 音声処理（DSP）
| 機能 | 内容 |
|------|------|
| ピッチシフト | ±12半音範囲で音程変更（SoundTouch利用） |
| フォルマント変換 | 性別傾向の声質変更（独自FFT実装） |
| EQ | Low/Mid/Highの3バンドIIRフィルタ |
| エコー / リバーブ | 遅延時間・減衰率をGUIから設定可能 |
| ノイズ抑制 | SpeexDSPまたはWebRTC NS利用 |
| ゲイン調整 | 入力・出力の音量制御 |

### 3.3 プリセット機能
- エフェクト設定をJSONで保存・読込可能  
- 例：「女性風」「ロボット声」「低音ボイス」など

### 3.4 モニタリング
- 入出力波形のリアルタイム描画（WPF Canvas）
- VUメータ表示

### 3.5 GUI（WPF）
| 機能 | 内容 |
|------|------|
| デバイス選択 | マイク・出力先をComboBoxで切替 |
| スライダーUI | ピッチ、フォルマント、EQ、エコー等のパラメータ制御 |
| 波形描画 | 音声波形とレベルメータ表示 |
| 設定ボタン | プリセット保存・読込 |
| 起動・停止 | 音声処理の開始／停止制御 |

## 5. 使用ライブラリ候補

| 分類 | ライブラリ | 用途 |
|------|-------------|------|
| 音声I/O | [**NAudio**](https://github.com/naudio/NAudio) | WASAPI入力・出力制御 |
| ピッチシフト | [**SoundTouch.NET**](https://github.com/Jobeso/SoundTouch.NET) | ピッチ・テンポ変換 |
| EQ / フィルタ | 自作IIR/Biquadまたは**NWaves** | 3バンドEQ実装 |
| リバーブ / エコー | **NWaves** | ディレイライン処理 |
| FFT | **Math.NET Numerics** | フォルマント処理用FFT |
| ノイズ除去 | **WebRTC Voice Activity Detection (C#ラッパ)** | 入力ノイズ軽減 |
| 設定保存 | **System.Text.Json** | プリセット管理 |

---

## 6. データフロー

```
[マイク入力 (NAudio)]
   ↓ BufferedWaveProvider
[エフェクトパイプライン]
   ├─ PitchShift (SoundTouch)
   ├─ Formant (FFT)
   ├─ EQ (Biquad)
   ├─ Reverb (NWaves)
   └─ NoiseReduction
   ↓
[WaveOut / WasapiOut]
[出力デバイス (VB-Cableなど)]
```
